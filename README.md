## REPL 功能

交互式环境下支持以下功能：

### 多行输入

自动检测括号/字符串是否闭合，未闭合时显示 `... ` 续行提示：

```
>>> (define (fib n)
...   		(if (<= n 1)
...       	n
...       	(+ (fib (- n 1)) (fib (- n 2)))))
()
```

### 自动缩进

续行时光标自动对齐到第一个参数列，或缩进 2 格。

### 语法高亮

输入时关键字、内置函数、数字、字符串、括号等以不同颜色区分。

### Tab 补全

按 Tab 自动补全内置函数名和特殊形式（`define`、`lambda`、`car`、`cdr` 等）。

### 输出着色

求值结果根据类型显示不同颜色：
- 数字 → 绿色
- 字符串 → 红色
- 布尔值 → 黄色
- 符号 → 青色
- 过程 → 品红
- 空列表 → 灰色

### 快捷键

| 按键 | 功能 |
|------|------|
| 方向键 | 移动光标 |
| Ctrl+D | 退出 REPL |
| Tab | 补全 |
